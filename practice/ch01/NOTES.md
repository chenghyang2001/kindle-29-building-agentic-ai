# K29 第 1 章演練紀錄

## 做了什麼

- 讀 K29《Building Agentic AI》第 1 章「代理式 AI 是什麼」的主題。
- 寫了 `PATTERNS.md`（繁體中文），內容包含：
  1. 代理式 AI 的四個核心特徵：自主性、目標導向、工具使用、記憶／回饋迴圈，並各自對照 Claude Code 的具體表現。
  2. 7 大設計模式：ReAct、Reflection、Tool Use、Planning、Multi-Agent、Sequential、Human-in-the-loop。每個模式都有「一句定義／何時用／在 Claude Code 裡長什麼樣」三段。
  3. 補充：模式之間如何疊加的示意圖，以及「你的情況 → 先考慮哪個模式」速查表。
- 模式：kindle-drill 快速 demo 模式（專案 CLAUDE.md 已豁免三 agent 流程），全自動、不提問。

## 驗證結果

- 結構檢查（grep 計數）：
  - 四個核心特徵都出現在特徵表中。
  - 7 個模式標題（`### 1.` ~ `### 7.`）齊全。
  - 每個模式都有「定義」「何時用」「在 Claude Code 裡」三個欄位，各 7 次。
- 內容檢查：Claude Code 例子都用真實存在的功能（Plan 模式／Shift+Tab、Agent 工具與 sub-agent、權限提示、hooks、MCP、`/code-review`、TodoWrite），沒有虛構指令。
- 沒有程式碼可執行，所以沒有跑測試；驗證以文件結構與內容正確性為主。

## 和書上做法的差異

- **書上**：第 1 章是概念章，介紹什麼是代理式 AI、它和傳統 LLM 應用的差別，以及常見設計模式，**沒有動手步驟**。
- **這裡**：因為沒有可演練的程式，改成寫一份「概念 ↔ Claude Code」對照文件，把每個抽象模式連到日常實際在用的工具，加深記憶。
- 額外加了兩件書上未必有的東西：
  - Sequential 與 Planning 的差別（順序由設計者寫死 vs 由模型臨場決定），因為兩者最容易混淆。
  - 模式疊加示意圖與選擇速查表，方便之後章節實作時回來查。
- 模式清單以使用者指定的 7 個為準；書中對模式的命名或分類若略有不同，以後續章節為準再更新。
