## 和書上做法的差異

| 面向 | 書上（第 2 章） | 本演練 |
| --- | --- | --- |
| 性質 | 概念章：介紹各層有哪些技術與廠商選項 | 把概念落地成**一個真實專案**的選型決策 |
| 選型 | 列舉多種選項，不替讀者做決定 | 每層只選一個主方案，並寫出理由與被淘汰的替代方案 |
| 具體度 | 偏通用架構圖 | 加入具體參數：max_turns、成本上限、每日 PR 上限、golden set 門檻、token 權限範圍 |
| 安全層 | 原則性說明 | 拆成工具允許／禁止清單、分支保護、Draft PR、prompt injection 包裝等可執行措施 |
| 工具生態 | 依書寫作時點的框架 | 改用 Claude Agent SDK + GitHub MCP server 的 2026 實務組合 |
