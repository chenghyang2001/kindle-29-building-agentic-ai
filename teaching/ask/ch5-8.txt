### 第 6 章：MCP — Connecting Claude Code to Everything
* **(a) 操作步驟與指令**：
  * **配置本地 MCP 伺服器 (stdio)**：在專案 `.mcp.json`、`CLAUDE.md` 或設定檔的 
`mcpServers` 中進行配置。例如連接本地 PostgreSQL 資料庫 [9, 10]：
    ```json
    {
      "mcpServers": {
        "postgres": {
          "command": "npx",
          "args": ["-y", "@modelcontextprotocol/server-postgres", 
"postgresql://localhost:5432/myapp_dev"]
        }
      }
    }
    ```
  * **配置遠端 MCP 伺服器 (HTTP / OAuth2)**：設定遠端服務（如 
Jira），首次調用會觸發瀏覽器 OAuth2 驗證流程 [11]：
    ```json
    {
      "mcpServers": {
        "jira": {
          "url": "",
          "auth": {
            "type": "oauth2",
            "clientId": "your-client-id",
            "scopes": ["read:jira-work", "write:jira-work"]
          }
        }
      }
    }
    ```
  * **開發自訂 MCP 伺服器**：建立 TypeScript 伺服器檔案（如 `server.ts`）[12]。
    * *程式碼重點*：從 `@modelcontextprotocol/sdk/server` 引入 `McpServer`，使用
`server.tool(...)` 宣告工具（如 `deploy-staging`）、使用 `server.resource(...)` 
提供唯讀資料（如 `deploy-status`，URI 為 `deploy://status`），最後呼叫 
`server.start()` [12, 13]。
  * **用到的 SDK／套件**：`@modelcontextprotocol/sdk`（或 
`@modelcontextprotocol/sdk/server`）、`@modelcontextprotocol/server-postgres`；N
ode.js / npx / TypeScript。

15]。
  * **「實作-測試-文檔」三軌並行流程**：讓 1 個子代理寫功能代碼、1 
個寫測試框架與 stub、1 個撰寫 API 文檔與 README，提升並列效率 [16]。

**大規模模組遷移流程**：將程式碼庫劃分為獨立模組，指派多個子代理平行執行遷移規則

  * **邊界與溝通管理**：子代理預設共享檔案系統（Shared 
Context），需在提示詞中明確劃分檔案與目錄的權責邊界（Ownership 
boundaries）以避免修改衝突 [18]；或採用訊息傳遞（Message 
Passing）機制進行順序性傳遞 [19]。
  * **用到的 SDK／套件**：Claude Code 
CLI（主代理自動內建調度子代理機制，無需額外手動安裝 external SDK）[20]。

  * **配置自動防護網（Hooks）**：
    * **建立檔案**：在專案設定檔（如 `.mcp.json` 或 Claude Code 
設定/`settings.json`）中加入 `"hooks"` 物件 [25]。
    * **設定重點**：設定 `afterFileWrite` (After Hook)，在 Agent 
修改檔案後自動觸發格式化工具（如 Prettier）[25]：
      ```json
      {
        "hooks": {
          "afterFileWrite": {
            "command": "npx prettier --write ${file}",
            "pattern": "**/*.{ts,tsx,js,jsx}"
          }
        }
      }
      ```
      亦可設定 Linter 檢查、TypeScript 型別檢查及 Commit 前的測試驗證（Before 
Hook）[25, 26]。
  * **用到的 SDK／套件**：Claude Code CLI；本地格式化與檢查工具（Prettier, 
ESLint, Black, gofmt, rustfmt, TypeScript `tsc`）[25]。
